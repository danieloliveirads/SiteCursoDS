Objetivo

O curso ENSINO MÉDIO COM HABILITAÇÃO PROFISSIONAL DE TÉCNICO EM DESENVOLVIMENTO DE SISTEMAS — 2ª SÉRIE (NOTURNO) tem como objetivos capacitar o aluno para:

  • Aprofundar conhecimentos em desenvolvimento web avançado;
  • Gerenciar estruturas de dados complexas em bancos de dados relacionais;
  • Analisar e projetar sistemas de software seguindo metodologias e padrões estabelecidos;
  • Desenvolver aplicações completas de sistemas com qualidade e eficiência;
  • Agir com responsabilidade profissional e ética nas relações organizacionais;
  • Aplicar conceitos de conduta profissional em diversos contextos de trabalho.
I.21 PROGRAMAÇÃO WEB II
Função: Desenvolvimento avançado de aplicações web dinâmicas e interativas  •  Classificação: Execução
Competências ProfissionaisHabilidades
  1. Desenvolver aplicações web dinâmicas utilizando frameworks e bibliotecas avançadas.
  2. Implementar funcionalidades interativas no lado do cliente e do servidor.
  1. 1.1 Aplicar frameworks modernos no desenvolvimento web (React, Vue, Angular).
  2. 1.2 Implementar autenticação e autorização em aplicações web.
  3. 2.1 Integrar APIs de terceiros em aplicações web.
  4. 2.2 Otimizar performance e acessibilidade em aplicações web.
Bases Tecnológicas
1. Frameworks Frontend
  • React: componentes, hooks, gerenciamento de estado;
  • Vue.js: reactive data, componentes reutilizáveis;
  • Angular: decorators, serviços, dependency injection.
2. Desenvolvimento Backend Avançado
  • Frameworks web (Node.js, Express, Django, Flask);
  • Arquitetura MVC e padrões de design;
  • Middleware e tratamento de erros;
  • Autenticação JWT e OAuth2.
3. Integração com APIs
  • Consumo de APIs RESTful;
  • GraphQL: conceitos e implementação;
  • Teste de APIs com Postman e ferramentas similares.
4. Banco de Dados em Aplicações Web
  • ORM (Object-Relational Mapping);
  • Conexão com bancos de dados em aplicações web;
  • Migrations e versionamento de schema.
5. Performance e Otimização
  • Cache de dados e estratégias de otimização;
  • Minificação e compressão de assets;
  • Lazy loading e code splitting.
6. Acessibilidade e SEO
  • WCAG e padrões de acessibilidade;
  • Meta tags e otimização para SEO;
  • Testes de acessibilidade.
Informações Complementares
Atribuições e Responsabilidades
  • Desenvolver aplicações web completas com funcionalidades avançadas, garantindo qualidade, segurança e performance.
Valores e Atitudes
  • Promover código limpo e bem documentado.
  • Responsabilizar-se pela qualidade das soluções.
Competências Pessoais / Socioemocionais
  • Demonstrar capacidade de aprendizado contínuo em tecnologias emergentes.
  • Trabalhar efetivamente em equipes multidisciplinares.
Orientações

Sugestões de tecnologias: React, Vue.js, Angular; Node.js, Express, Python (Django/Flask); PostgreSQL, MongoDB em aplicações web; Docker para containerização.

I.26 BANCOS DE DADOS II
Função: Gerenciamento avançado de dados e otimização de bancos de dados  •  Classificação: Execução
Competências ProfissionaisHabilidades
  1. Otimizar estruturas de dados em bancos de dados relacionais e não-relacionais.
  2. Implementar segurança e backup em ambientes de banco de dados.
  1. 1.1 Criar índices e otimizar consultas SQL.
  2. 1.2 Implementar denormalização e particionamento de dados.
  3. 2.1 Configurar políticas de backup e recuperação de dados.
  4. 2.2 Implementar controle de acesso e criptografia de dados.
Bases Tecnológicas
1. Otimização de Bancos de Dados Relacionais
  • Índices e planos de execução;
  • Otimização de consultas e subqueries;
  • Particionamento de tabelas e sharding;
  • Denormalização estratégica.
2. Bancos de Dados Não-Relacionais
  • Modelos NoSQL (Documentos, Chave-Valor, Grafos);
  • MongoDB, Redis, Neo4j;
  • Escalabilidade horizontal e replicação.
3. Administração de Banco de Dados
  • Configuração e tuning de SGBD;
  • Monitoramento e logs;
  • Gerenciamento de usuários e permissões.
4. Backup e Recuperação
  • Estratégias de backup (full, incremental, diferencial);
  • Disaster recovery e high availability;
  • Testes de recuperação.
5. Segurança em Banco de Dados
  • Criptografia de dados em repouso e em trânsito;
  • Controle de acesso baseado em funções (RBAC);
  • Auditoria e compliance (LGPD, GDPR).
6. Data Warehouse e Big Data
  • ETL (Extract, Transform, Load);
  • Data lakes e data marts;
  • Análise de dados em larga escala.
Informações Complementares
Atribuições e Responsabilidades
  • Administrar e otimizar ambientes de banco de dados, garantindo performance, segurança e disponibilidade.
Valores e Atitudes
  • Zelar pela integridade e segurança dos dados.
  • Documentar procedimentos e configurações.
Competências Pessoais / Socioemocionais
  • Demonstrar responsabilidade com dados sensíveis.
  • Manter-se atualizado com tecnologias de banco de dados.
Orientações

Sugestões de tecnologias: PostgreSQL, MySQL, Oracle; MongoDB, Redis, Cassandra; AWS RDS, Azure Database; Ferramentas de administração: pgAdmin, MySQL Workbench, DBeaver.

I.23 ANÁLISE E PROJETO DE SISTEMAS
Função: Análise, design e documentação de sistemas de software  •  Classificação: Planejamento
Competências ProfissionaisHabilidades
  1. Analisar requisitos funcionais e não-funcionais de sistemas.
  2. Projetar arquitetura de software seguindo padrões estabelecidos.
  1. 1.1 Elicitar e documentar requisitos de sistemas.
  2. 1.2 Analisar viabilidade técnica e econômica de projetos.
  3. 2.1 Elaborar diagramas UML e modelos de sistema.
  4. 2.2 Documentar especificações técnicas de forma clara e precisa.
Bases Tecnológicas
1. Elicitação de Requisitos
  • Técnicas de levantamento de requisitos;
  • Entrevistas, focus groups e workshops;
  • Requisitos funcionais e não-funcionais;
  • Casos de uso e stories.
2. Análise de Sistemas
  • Análise de viabilidade (técnica, econômica, operacional);
  • Diagrama de fluxo de dados (DFD);
  • Modelos de dados e relacionamentos;
  • Análise de riscos.
3. Design de Sistemas
  • Padrões de design (SOLID, Design Patterns);
  • Arquitetura de software;
  • Design de banco de dados;
  • Interfaces e experiência do usuário.
4. Unified Modeling Language (UML)
  • Diagramas de classe, sequência e atividade;
  • Diagramas de componentes e deployment;
  • Ferramentas de modelagem (Enterprise Architect, Lucidchart).
5. Documentação de Sistemas
  • Especificação funcional e técnica;
  • Manuais de usuário e administrador;
  • Documentação de API;
  • Versioning e rastreabilidade.
6. Métricas e Qualidade
  • Métricas de software (complexidade, coesão);
  • Testes e validação;
  • Revisão de código e testes de qualidade.
Informações Complementares
Atribuições e Responsabilidades
  • Analisar e projetar soluções de software que atendam aos requisitos dos clientes com qualidade e eficiência.
Valores e Atitudes
  • Comunicação clara com stakeholders.
  • Documentação precisa e atualizada.
Competências Pessoais / Socioemocionais
  • Pensamento crítico na análise de problemas.
  • Trabalho colaborativo com times multidisciplinares.
Orientações

Sugestões de ferramentas: Enterprise Architect, Lucidchart, Miro, Figma para design; Jira para gerenciamento de requisitos.

I.22 DESENVOLVIMENTO DE SISTEMAS I
Função: Desenvolvimento integrado de aplicações completas  •  Classificação: Execução
Competências ProfissionaisHabilidades
  1. Desenvolver aplicações de sistemas completas integrando frontend, backend e banco de dados.
  2. Aplicar testes e garantir qualidade no desenvolvimento.
  1. 1.1 Implementar funcionalidades completas de ponta a ponta.
  2. 1.2 Integrar componentes frontend com APIs backend.
  3. 2.1 Executar testes unitários, integração e aceitação.
  4. 2.2 Aplicar debugging e tratamento de erros em produção.
Bases Tecnológicas
1. Desenvolvimento Full-Stack
  • Integração frontend-backend;
  • Comunicação entre camadas da aplicação;
  • Tratamento de requisições HTTP;
  • Gerenciamento de sessão e estado.
2. Persistência de Dados
  • Operações CRUD completas;
  • Transações e consistência de dados;
  • Caching e performance.
3. Testes de Software
  • Testes unitários (Jest, Pytest, JUnit);
  • Testes de integração;
  • Testes e2e (Selenium, Cypress);
  • Test-driven development (TDD).
4. Debugging e Troubleshooting
  • Ferramentas de debugging (DevTools, profilers);
  • Logging e monitoramento;
  • Performance profiling.
5. Deployment e CI/CD
  • Ambientes de desenvolvimento, teste e produção;
  • Integração contínua e entrega contínua;
  • Containerização com Docker;
  • Orquestração com Kubernetes.
6. Segurança em Aplicações
  • OWASP Top 10;
  • Proteção contra ataques comuns;
  • Validação e sanitização de inputs.
Informações Complementares
Atribuições e Responsabilidades
  • Desenvolver aplicações robustas e seguras com qualidade comprovada através de testes.
Valores e Atitudes
  • Qualidade acima de quantidade.
  • Responsabilidade com prazos e entregas.
Competências Pessoais / Socioemocionais
  • Persistência na resolução de problemas técnicos complexos.
  • Colaboração efetiva em equipes de desenvolvimento.
Orientações

Sugestões de tecnologias: React/Node.js, Vue/Django, Angular/ASP.NET; Jest, Pytest para testes; Docker, GitLab CI/CD para deployment.

  2. Compreender e aplicar conceitos de responsabilidade social nas organizações.
  1. 1.1 Identificar e agir conforme os códigos de ética profissional.
  2. 1.2 Demonstrar integridade e respeito nas relações de trabalho.
  3. 2.1 Compreender o impacto social das ações organizacionais.
  4. 2.2 Contribuir para práticas sustentáveis e socialmente responsáveis.
Bases Tecnológicas
1. Ética Profissional

  • Códigos de ética profissional em TI;
  • Conflito de interesses e dilemas éticos;
  • Responsabilidade profissional.
2. Relações Profissionais
  • Comunicação efetiva e respeitosa;
  • Relacionamento interpessoal no ambiente de trabalho;
  • Resolução de conflitos;
  • Trabalho em equipe e colaboração.
3. Legislação Laboral
  • Direitos e deveres do trabalhador;
  • Contrato de trabalho;
  • Segurança e saúde ocupacional;
  • Legislação ambiental.
4. Responsabilidade Social

  • Sustentabilidade nas organizações;
